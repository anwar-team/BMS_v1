أنت مساعد ترحيل كود Laravel → Livewire v3. المطلوب تنفيذ التحويل مع:
(أ) الحفاظ الكامل على التصميم (HTML/CSS/classes) دون أي تغيير،
(ب) الحفاظ على طريقة جلب البيانات الحالية (نفس الاستعلامات/Repositories/Scopes/Endpoints) دون استبدال المنطق.

========================
🎯 الأهداف
1) اكتشاف جميع الجداول (كتب/مؤلفين…) وتوثيق مواقعها وعناصرها (أعمدة، فلاتر، أزرار).
2) تحويل كل جدول إلى Livewire **مع إعادة استخدام نفس طريقة الجلب الحالية**:
   - إذا كان الجلب يتم عبر Controller + Repository/Scopes → استخدم نفس الواجهة (methods) داخل Livewire.
   - إذا كان الجلب يتم عبر Endpoint (API/DataTables server-side) → استخدم **Adapter** داخل المكوّن لاستدعاء نفس الـ Endpoint، ثم اعرض النتائج كما هي.
3) تحويل صفحات "كل الكتب" و"كل المؤلفين" إلى Livewire (بحث/فرز/ترقيم) **بدون تعديل التصميم**.
4) إضافة تعليقات واضحة على كل تغيير + تقريرين في docs/ يشرحان الاكتشاف والتنفيذ.

========================
🧩 قواعد صارمة للحفاظ على التصميم
- يُمنع تعديل:
  - بنية الـ HTML (thead/tbody/tr/td)
  - أسماء أو ترتيب الأعمدة
  - أي CSS classes (Tailwind/Bootstrap/Utility)
- فقط أضف سمات Livewire (wire:model/ wire:click) عند الحاجة، **بدون** حذف أو تبديل classes.
- إن وُجد DataTables/JS للبحث/الفرز:
  - عطّل **الوظائف المتعارضة فقط** (init/filter/sort) واحتفظ بكل CSS/ستايلات.
  - ضع تعليق Blade يشرح التعطيل.

========================
🛠️ الحفاظ على طريقة جلب البيانات (بدون تغييرات منطقية)
اعمل بأحد الوضعين حسب المشروع:

(وضع A — Eloquent/Repository قائم):
- استخدم نفس Repository/Scopes/Query Methods المستعملة في الـ Controller.
- ممنوع كتابة Query جديدة مختلفة؛ فقط استدعِ نفس الدوال (مثلاً: BookRepository::indexQuery($filters)).
- لو الاستعلام موجود داخل Controller: استخرج منطق الاستعلام إلى Trait/Service مشتركة:
  - أنشئ Trait في app/Queries/BooksIndexQuery.php (أو Service app/Services/BooksIndex.php)
  - **استخدم نفس الـ Trait/Service في الـ Controller وLivewire** لتضمن عدم تغيّر السلوك.
- احفظ نفس eager-load والـ where/when/filters كما هي.

(وضع B — API/DataTables server-side):
- أنشئ Adapter بسيط داخل المكوّن يستدعي نفس الـ Endpoint (باستخدام Http::get أو Guzzle) ويحوّل JSON → Collection/Paginator لعرضها.
- لا تغيّر الـ Endpoint ولا صيغة الـ payload ولا البارامترات (search, sort, page, per_page…)، فقط مرّرها من خصائص Livewire كما هي.

✍️ قوالب كود (اختر A أو B حسب طريقتكم الحالية)

(قالب A — Repository/Scopes محفوظة)
--------------------------------
<?php

namespace App\Livewire\Tables;

use Livewire\Attributes\Url;
use Livewire\Component;
use Livewire\WithPagination;
use App\Repositories\BookRepository; // نفس الريبو المستخدم في الـ Controller

class BooksTable extends Component
{
    use WithPagination;

    /** @var int|null نفس الفلاتر المستخدمة سابقًا */
    public ?int $authorId = null;
    public ?int $categoryId = null;

    /** @var int يحاكي نفس حجم الصفحة الافتراضي */
    public int $pageSize = 10;

    /** @var string بحث مطابق لمنطق الـ Controller/Repository */
    #[Url] public string $search = '';
    #[Url] public string $sortField = 'title';
    #[Url] public string $sortDir   = 'asc';

    // [Preserve-Data-Source] استخدم نفس الريبو بدون تعديل المنطق
    protected BookRepository $repo;

    public function boot(BookRepository $repo): void
    {
        $this->repo = $repo;
    }

    public function mount(?int $authorId = null, ?int $categoryId = null, int $pageSize = 10): void
    {
        $this->authorId   = $authorId;
        $this->categoryId = $categoryId;
        $this->pageSize   = $pageSize;
    }

    public function updatingSearch(): void { $this->resetPage(); }

    public function setSort(string $field): void
    {
        $this->sortDir = ($this->sortField === $field && $this->sortDir === 'asc') ? 'desc' : 'asc';
        $this->sortField = $field;
        $this->resetPage();
    }

    public function render()
    {
        // [Preserve-Data-Source] نعيد استخدام نفس الدالة التي يستخدمها الـ Controller
        $filters = [
            'author_id' => $this->authorId,
            'category_id' => $this->categoryId,
            'search' => $this->search,
            'sort_field' => $this->sortField,
            'sort_dir' => $this->sortDir,
            'per_page' => $this->pageSize,
        ];

        $books = $this->repo->indexPaginated($filters); // نفس المنهجية القائمة

        return view('livewire.tables.books-table', compact('books'));
    }
}

(قالب B — API/DataTables Adapter)
--------------------------------
<?php

namespace App\Livewire\Tables;

use Illuminate\Support\Facades\Http;
use Livewire\Attributes\Url;
use Livewire\Component;

class BooksTable extends Component
{
    #[Url] public string $search = '';
    #[Url] public string $sortField = 'title';
    #[Url] public string $sortDir   = 'asc';
    public int $page = 1;
    public int $pageSize = 10;

    /** [Preserve-Data-Source] نفس الـ Endpoint الذي تستخدمه الصفحة القديمة */
    protected string $endpoint = '/api/books'; // لا تغيّر؛ استخرجه من الكود لو مختلف

    public function setSort(string $field): void
    {
        $this->sortDir = ($this->sortField === $field && $this->sortDir === 'asc') ? 'desc' : 'asc';
        $this->sortField = $field;
        $this->page = 1;
    }

    public function render()
    {
        // مرّر نفس أسماء البارامترات كما في الكود القديم تمامًا
        $response = Http::get($this->endpoint, [
            'search'    => $this->search,
            'sort'      => $this->sortField,
            'direction' => $this->sortDir,
            'page'      => $this->page,
            'per_page'  => $this->pageSize,
        ])->json();

        // حوّل JSON إلى بنية قابلة للعرض (لا تغيّر الحقول)
        $books = collect($response['data'] ?? []);
        $meta  = $response['meta']  ?? [];

        return view('livewire.tables.books-table', [
            'books' => $books,
            'meta'  => $meta,
        ]);
    }
}
