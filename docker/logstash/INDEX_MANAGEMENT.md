# 🔍 دليل إدارة الفهارس في نظام البحث

## 📋 الوضع الحالي للفهرس:

### **🎯 سيستخدم نفس الفهرس الموجود:**
- **اسم الفهرس:** `pages` (مطابق لـ Laravel Scout)
- **النتيجة:** دمج البيانات مع الفهرس الحالي
- **المزايا:** استمرارية البحث بدون انقطاع

## 🔄 سيناريوهات العمل:

### **1. إذا كان فهرس `pages` موجود:**
```
✅ سيتم دمج البيانات الجديدة
✅ تحديث الصفحات الموجودة
✅ الاحتفاظ بالبيانات القديمة
✅ تطبيق المحلل العربي الجديد
```

### **2. إذا لم يكن الفهرس موجود:**
```
🆕 إنشاء فهرس جديد بنفس الاسم
🔧 تطبيق template العربي المحسن
📊 فهرسة جميع البيانات من الصفر
```

## 🎛️ خيارات تحديد الفهرس للبحث:

### **1. البحث في فهرس محدد (Laravel Scout):**
```php
// البحث في فهرس معين
Page::search('النص المطلوب')->within('pages');

// أو استخدام فهرس آخر
Page::search('النص المطلوب')->within('pages_backup');
```

### **2. البحث المباشر في Elasticsearch:**
```bash
# البحث في فهرس pages الحالي
curl -X GET "145.223.98.97:9201/pages/_search" \
-H "Content-Type: application/json" \
-d '{
  "query": {
    "match": {
      "content": "النص المطلوب"
    }
  }
}'

# البحث في فهرس آخر
curl -X GET "145.223.98.97:9201/pages_logstash/_search" \
-H "Content-Type: application/json" \
-d '{
  "query": {
    "match": {
      "content": "النص المطلوب"
    }
  }
}'
```

### **3. تعديل اسم الفهرس في Logstash:**
```ruby
# لإنشاء فهرس منفصل
index => "pages_logstash_%{+YYYY.MM}"

# أو فهرس ثابت منفصل
index => "pages_advanced"
```

## 🚨 خيارات الإعداد المختلفة:

### **الخيار 1: نفس الفهرس (الحالي) ✅**
```yaml
المزايا:
- استمرارية البحث
- عدم الحاجة لتعديل الكود
- دمج بيانات Laravel Scout + Logstash

العيوب:
- قد تحدث تضارب في البيانات المؤقت
```

### **الخيار 2: فهرس منفصل للـ Logstash**
```yaml
المزايا:
- فصل كامل بين النظامين
- إمكانية مقارنة النتائج
- تجنب التضارب

العيوب:
- الحاجة لتعديل كود البحث
- إدارة فهرسين منفصلين
```

### **الخيار 3: استبدال كامل**
```yaml
المزايا:
- نظام موحد من Logstash
- محلل عربي محسن
- تزامن أفضل مع قاعدة البيانات

العيوب:
- الحاجة لإيقاف Laravel Scout
- فترة انقطاع قصيرة أثناء الانتقال
```

## 🛠️ لتطبيق خيار مختلف:

### **لإنشاء فهرس منفصل:**
```bash
# تعديل ملف pipeline
# تغيير: index => "pages"
# إلى: index => "pages_logstash"
```

### **لاستخدام فهرس شهري:**
```bash
# تغيير إلى: index => "pages_%{+YYYY.MM}"
# سيكون: pages_2025.09, pages_2025.10, إلخ
```

### **لمقارنة الفهارس:**
```bash
# عدد الوثائق في كل فهرس
curl "http://145.223.98.97:9201/pages/_count"
curl "http://145.223.98.97:9201/pages_logstash/_count"

# قائمة جميع الفهارس
curl "http://145.223.98.97:9201/_cat/indices"
```
