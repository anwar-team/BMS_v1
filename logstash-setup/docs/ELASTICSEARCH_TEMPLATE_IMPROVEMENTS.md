## 🎯 التحسين الثاني: تطوير حقل أسماء المؤلفين

### الهدف

إضافة مستويات مختلفة للبحث في أسماء المؤلفين.

### الكود المقترح

```json
{
  "mappings": {
    "properties": {
      "author_names": {
        "type": "text",
        "analyzer": "arabic_analyzer",
        "search_analyzer": "arabic_analyzer",
        "fields": {
          "exact": {
            "type": "text",
            "analyzer": "arabic_title_analyzer",
            "boost": 2.5
          },
          "scholars": {
            "type": "text",
            "analyzer": "arabic_scholars_analyzer",
            "boost": 2.0
          },
          "keyword": {
            "type": "keyword",
            "boost": 3.0
          },
          "normalized": {
            "type": "text",
            "analyzer": "arabic_search_analyzer"
          }
        }
      }
    }
  }
}
```

### الفوائد

- **exact**: بحث دقيق في الأسماء
- **scholars**: بحث متخصص للعلماء مع المرادفات
- **keyword**: مطابقة تامة للاسم
- **normalized**: بحث مبسط بدون تعقيدات

## 📈 التحسين الثالث: تحسين أولوية البحث (Boosting)

### الهدف

إعطاء أولوية مختلفة للحقول حسب أهميتها.

### الكود المقترح

```json
{
  "mappings": {
    "properties": {
      "book_title": {
        "type": "text",
        "analyzer": "arabic_analyzer",
        "search_analyzer": "arabic_analyzer",
        "boost": 2.0,
        "fields": {
          "exact": {
            "type": "text",
            "analyzer": "arabic_title_analyzer",
            "boost": 3.5
          },
          "advanced": {
            "type": "text",
            "analyzer": "arabic_advanced_analyzer",
            "boost": 2.5
          }
        }
      },
      "content": {
        "type": "text",
        "analyzer": "arabic_analyzer",
        "search_analyzer": "arabic_analyzer",
        "boost": 1.0,
        "fields": {
          "advanced": {
            "type": "text",
            "analyzer": "arabic_advanced_analyzer",
            "search_analyzer": "arabic_search_analyzer",
            "boost": 1.5
          },
          "raw": {
            "type": "keyword",
            "boost": 4.0
          }
        }
      }
    }
  }
}
```

### ترتيب الأولوية

1. **المطابقة التامة للمحتوى (4.0)** - أعلى أولوية
2. **المطابقة الدقيقة للعنوان (3.5)** - أولوية عالية جداً
3. **اسم المؤلف الدقيق (3.0)** - أولوية عالية
4. **العنوان المتقدم (2.5)** - أولوية متوسطة عالية
5. **اسم المؤلف العلماء (2.0)** - أولوية متوسطة
6. **العنوان العادي (2.0)** - أولوية متوسطة
7. **المحتوى المتقدم (1.5)** - أولوية منخفضة متوسطة
8. **المحتوى العادي (1.0)** - الأساس

