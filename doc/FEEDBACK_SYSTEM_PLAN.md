# 📋 خطة عمل: نظام الملاحظات والشكاوى

## 🎯 الهدف
إنشاء نظام متكامل لاستقبال ملاحظات وشكاوى الزوار مع رسالة ترحيبية للموقع الجديد

---

## 📊 المكونات الرئيسية

### 1️⃣ **قاعدة البيانات (Migration)**
```php
Table: feedback_complaints
- id (bigint, primary key)
- name (string, nullable) - اسم المستخدم (اختياري)
- email (string, nullable) - البريد الإلكتروني (اختياري)
- type (enum: 'feedback', 'complaint') - نوع الرسالة
- subject (string) - الموضوع
- message (text) - المحتوى (إلزامي)
- status (enum: 'pending', 'in_progress', 'resolved') - الحالة
- priority (enum: 'low', 'medium', 'high') - الأولوية
- admin_notes (text, nullable) - ملاحظات الإدارة
- ip_address (string, nullable) - عنوان IP
- user_agent (text, nullable) - معلومات المتصفح
- created_at (timestamp)
- updated_at (timestamp)
```

**ملاحظة مهمة:** الحقول الإلزامية فقط هي: type, subject, message

---

## 🎨 واجهة المستخدم

### 1️⃣ **رسالة الترحيب (Welcome Modal)**
**الموقع:** تظهر عند أول زيارة للموقع

**المحتوى:**
```
🎉 مرحباً بك في مكتبة المتكاملة

بحمد الله تعالى، تم إطلاق الموقع الجديد لمكتبة المتكاملة!

📚 ماذا نقدم؟
• بحث فوري وسريع في آلاف الكتب الإسلامية
• فلترة متقدمة حسب القسم، المؤلف، والتاريخ
• واجهة عصرية وسهلة الاستخدام
• محتوى موثوق ومُنظم

⚠️ ملاحظة هامة:
هذا إطلاق تجريبي أولي، وقد تواجه بعض المشاكل التقنية.
نرحب بملاحظاتكم وشكاويكم لتحسين الخدمة.

[بدء التصفح] [إرسال ملاحظة]
```

### 2️⃣ **زر عائم للملاحظات (Floating Button)**
- موقع: أسفل يسار الشاشة (ثابت في جميع الصفحات)
- لون: green-800
- أيقونة: 💬 أو 📝
- نص: "ملاحظة؟" أو "شكوى؟"

### 3️⃣ **نموذج الإرسال (Feedback Form)**
**الحقول:**
```
1. نوع الرسالة (إلزامي):
   - ⭐ ملاحظة/اقتراح
   - ⚠️ شكوى/مشكلة

2. الموضوع (إلزامي)

3. الرسالة (إلزامي - textarea)

[إرسال] [إلغاء]
```

**Validation:**
- نوع الرسالة: إلزامي
- الموضوع: إلزامي، 3 أحرف على الأقل
- الرسالة: إلزامية، 10 أحرف على الأقل
- الاسم والإيميل: محذوفة من النموذج

## 🛠️ لوحة التحكم (Admin Panel)

### 1️⃣ **صفحة القائمة**
**الإحصائيات (Cards):**
```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│  الإجمالي    │ │  المعلقة     │ │ قيد المعالجة │ │   المحلولة   │
│     65       │ │     15       │ │      8       │ │     42       │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

**جدول:**
- ID
- النوع (ملاحظة/شكوى)
- الموضوع
- مقتطف من الرسالة
- الحالة
- الأولوية
- التاريخ
- الإجراءات

**الفلاتر:**
- حسب النوع (ملاحظة/شكوى)
- حسب الحالة
- حسب الأولوية
- حسب التاريخ
- بحث في الموضوع/الرسالة
