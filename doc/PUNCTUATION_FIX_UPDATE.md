# تحديث: إصلاح الأقواس والعلامات الاقتباس

**التاريخ:** أكتوبر 7، 2025  
**التحديث:** إضافة دعم للأقواس وعلامات الاقتباس

---

## 🔧 المشكلة الإضافية

المستخدم أبلغ عن:
- فقرة جديدة تُفتح بعد `()` أقواس
- فقرة جديدة تُفتح بعد `« »` علامات اقتباس

---

## ✅ الحل المُطبق

### **العلامات المضافة:**

#### **1. الأقواس العادية:**
```php
'/(\()\s*\n\s*/' => '$1',                       // After opening parenthesis (
'/(\))\s*\n\s*(?!\.)/' => '$1 ',                // After closing parenthesis )
```

**أمثلة:**
```
قبل: "الكتاب (\nوهو مفيد)"
بعد: "الكتاب (وهو مفيد)"
```

#### **2. الأقواس المعقوفة:**
```php
'/(\[)\s*\n\s*/' => '$1',                       // After opening bracket [
'/(\])\s*\n\s*(?!\.)/' => '$1 ',                // After closing bracket ]
```

**أمثلة:**
```
قبل: "انظر [\nص 45]"
بعد: "انظر [ص 45]"
```

#### **3. علامات الاقتباس المزدوجة (« »):**
```php
'/(«)\s*\n\s*/' => '$1 ',                       // After opening quote «
'/(»)\s*\n\s*(?!\.)/' => '$1 ',                 // After closing quote »
```

**أمثلة:**
```
قبل: "قال: «\nالعلم نور»"
بعد: "قال: « العلم نور»"
```

#### **4. علامات الاقتباس الأخرى:**
```php
'/(["\'\'])\s*\n\s*(?!\.)/' => '$1 ',           // After quotes " ' '
```

**أمثلة:**
```
قبل: "قال: "\nالحق واضح""
بعد: "قال: " الحق واضح""
```

## 📊 القائمة الكاملة للعلامات المدعومة

### **جميع العلامات التي لا تكسر السطر:**

| الرمز | الوصف | مثال |
|------|--------|------|
| `,` | فاصلة إنجليزية | `word, word` |
| `،` | فاصلة عربية | `كلمة، كلمة` |
| `;` | فاصلة منقوطة إنجليزية | `word; word` |
| `؛` | فاصلة منقوطة عربية | `كلمة؛ كلمة` |
| `:` | نقطتان | `قال: العلم` |
| `-` | شرطة قصيرة | `الكتاب - المفيد` |
| `–` | شرطة متوسطة | `2020–2021` |
| `—` | شرطة طويلة | `العلم—النور` |
| `(` | قوس فتح | `الكتاب (المفيد)` |
| `)` | قوس إغلاق | `(المفيد) جداً` |
| `[` | قوس معقوف فتح | `انظر [ص 10]` |
| `]` | قوس معقوف إغلاق | `[ص 10] للتفاصيل` |
| `«` | اقتباس مزدوج فتح | `قال: « النص»` |
| `»` | اقتباس مزدوج إغلاق | `« النص» انتهى` |
| `"` | اقتباس مزدوج | `"النص" واضح` |
| `'` | اقتباس مفرد | `'النص' قصير` |
| `'` | اقتباس مفرد منحني | `'word' here` |

### **العلامة الوحيدة التي تكسر السطر:**

| الرمز | الوصف | مثال |
|------|--------|------|
| `.` | نقطة نهاية الجملة | `الجملة الأولى.<br>الجملة الثانية` |

## 📝 ملاحظات مهمة

### **قاعدة الاستثناء:**

**الأقواس/الاقتباسات لا تكسر السطر إلا إذا جاءت قبل نقطة:**

```php
'/(\))\s*\n\s*(?!\.)/' => '$1 ',   // ✅ يزيل \n إلا إذا جاء بعده .
'/(\))\s*\n\s*\./' => '$1\n.',     // ❌ لا يُطبق - يحافظ على \n قبل .
```

**مثال:**
```
Input: "النص (مفيد)\n."
Output: "النص (مفيد)\n."  // يحافظ على السطر الجديد

Input: "النص (مفيد)\nوالآخر"
Output: "النص (مفيد) والآخر"  // يزيل السطر الجديد
```
