## 🎯 نظرة عامة

نظام الملاحظات والشكاوى هو حل متكامل يسمح لزوار موقع مكتبة المتكاملة بإرسال ملاحظاتهم وشكاويهم بسهولة تامة **بدون الحاجة للتسجيل أو إدخال معلومات شخصية**.

### 🎨 المكونات الرئيسية

1. **رسالة ترحيبية** - تظهر عند أول زيارة للموقع
2. **زر عائم** - متاح في جميع صفحات الموقع
3. **نموذج إرسال** - بسيط وسريع
4. **لوحة تحكم** - شاملة للإدارة

---

## ✨ المميزات

### للزوار:
- 🚫 **لا يتطلب تسجيل** - إرسال مجهول تماماً
- 📝 **نموذج بسيط** - 3 حقول فقط
- 🔒 **خصوصية كاملة** - لا نطلب اسم أو بريد إلكتروني
- ⚡ **إرسال فوري** - Ajax بدون إعادة تحميل
- 🎨 **تصميم عصري** - واجهة جذابة ومتجاوبة
- 💬 **زر عائم** - متاح في كل صفحة

### للإدارة:
- 📊 **إحصائيات شاملة** - عدد الرسائل حسب الحالة
- 🔍 **بحث متقدم** - فلترة حسب النوع والحالة والأولوية
- 📝 **إدارة كاملة** - عرض، تعديل، حذف
- 🏷️ **تصنيف مرئي** - ألوان مميزة لكل حالة
- 📅 **معلومات تقنية** - IP, User Agent, التواريخ
- 💾 **ملاحظات الإدارة** - توثيق الإجراءات

### تقنية:
- ⚡ **Ajax** - إرسال بدون reload
- 🔔 **Toast Notifications** - إشعارات فورية
- 💾 **LocalStorage** - تذكر الزيارات
- ✅ **Validation** - تحقق قوي من البيانات
- 🎯 **RESTful API** - معايير صناعية
- 🔒 **CSRF Protection** - حماية أمنية

## 📦 التثبيت

### المتطلبات:
- PHP >= 8.1
- Laravel >= 10.x
- MySQL/PostgreSQL
- Composer
- Node.js & NPM

### خطوات التثبيت:

1. **تشغيل Migration:**
```bash
php artisan migrate
```

2. **بناء الأصول:**
```bash
npm run build
```

3. **مسح الـ Cache (اختياري):**
```bash
php artisan cache:clear
php artisan config:clear
php artisan view:clear
```

4. **الوصول للنظام:**
- للزوار: الزر العائم في أي صفحة
- للإدارة: `/admin/feedback`

✅ **جاهز للاستخدام!**

## 🚀 الاستخدام

### للزوار

#### الطريقة الأولى - رسالة الترحيب:
1. افتح الموقع (ستظهر تلقائياً في أول زيارة)
2. اضغط "إرسال ملاحظة"
3. املأ النموذج وأرسل

#### الطريقة الثانية - الزر العائم:
1. انظر لأسفل يسار الشاشة
2. اضغط على الزر 💬
3. املأ النموذج:
   - **نوع الرسالة**: ملاحظة ⭐ أو شكوى ⚠️
   - **الموضوع**: عنوان مختصر
   - **الرسالة**: محتوى مفصل (10 أحرف كحد أدنى)
4. اضغط "إرسال"
5. ستظهر رسالة نجاح ✅

### للإدارة

#### الوصول للوحة التحكم:
```
URL: /admin/feedback
```

#### الإحصائيات:
- إجمالي الرسائل
- المعلقة ⏳
- قيد المعالجة 🔄
- المحلولة ✅

#### الفلاتر:
- بحث في الموضوع/المحتوى
- النوع (ملاحظة/شكوى)
- الحالة (معلقة/قيد المعالجة/محلولة)
- الأولوية (منخفضة/متوسطة/عالية)

#### إدارة الرسائل:
1. اضغط "عرض" لرؤية التفاصيل الكاملة
2. اضغط "تعديل" لتغيير الحالة والأولوية
3. أضف ملاحظات الإدارة لتوثيق الإجراءات

## 📊 قاعدة البيانات

### جدول: `feedback_complaints`

| الحقل | النوع | إلزامي | الوصف |
|------|------|--------|-------|
| `id` | bigint | نعم | المعرف الفريد |
| `type` | enum | نعم | feedback / complaint |
| `subject` | string | نعم | الموضوع |

| `user_agent` | text | لا | معلومات المتصفح |
| `created_at` | timestamp | تلقائي | تاريخ الإنشاء |
| `updated_at` | timestamp | تلقائي | تاريخ التحديث |

## 🔌 API Reference

### POST `/feedback`
**Public** - إرسال ملاحظة/شكوى

**Request:**
```json
{
  "type": "feedback",
  "subject": "اقتراح تحسين",
  "message": "أقترح إضافة خاصية البحث الصوتي"
}
```

**Response:**
```json
{
  "success": true,
  "message": "تم إرسال رسالتك بنجاح!",
  "data": { ... }
}
```

### GET `/admin/feedback`
**Admin** - عرض القائمة

**Query Parameters:**
- `type` - النوع
- `status` - الحالة
- `priority` - الأولوية
- `search` - البحث
- `page` - الصفحة

### PUT `/admin/feedback/{id}`
**Admin** - تحديث الحالة

**Request:**
```json
{
  "status": "resolved",
  "priority": "high",
  "admin_notes": "تم الحل"
}
```
