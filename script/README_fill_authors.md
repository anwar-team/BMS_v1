# تحديثات سكريبت fill_authors.py

## التحسينات المضافة

### 1. دعم التواريخ الهجرية والميلادية
- تم تحديث دالة `extract_years()` لتمييز بين التواريخ الهجرية والميلادية
- يتم تحديد نوع التاريخ بناءً على المؤشرات النصية مثل "هـ" للهجري و "م" للميلادي
- في حالة عدم وجود مؤشرات واضحة، يتم استخدام قاعدة: السنوات > 1500 تعتبر ميلادية، والأقل تعتبر هجرية

### 2. تحسين استخراج السيرة الذاتية
- تم تحديث دالة `parse_biography()` للحفاظ على تنسيق النص
- معالجة أفضل لعناصر HTML مثل `<br>` و `<p>`
- تنظيف المسافات الزائدة مع الحفاظ على فواصل الأسطر

### 3. منع تكرار المؤلفين
- تم تحديث دالة `generate_sql_upsert()` لاستخدام `INSERT ... ON DUPLICATE KEY UPDATE`
- إضافة فهرس فريد على عمود `full_name` لمنع التكرار
- عند وجود مؤلف بنفس الاسم، يتم تحديث بياناته بدلاً من إضافة سجل جديد
- استخدام `COALESCE()` للحفاظ على البيانات الموجودة إذا كانت البيانات الجديدة فارغة

### 4. تحديث قاعدة البيانات
- إضافة حقول `birth_year_type` و `death_year_type` لتخزين نوع التاريخ
- إضافة حقول `birth_year` و `death_year` لتخزين السنوات
- تحديد حالة `is_living` بناءً على وجود تاريخ الوفاة

## مخرجات SQL

السكريبت ينتج الآن INSERT statements تتضمن:
- `full_name`: الاسم الكامل
- `biography`: السيرة الذاتية مع التنسيق المحسن
- `madhhab`: المذهب الفقهي
- `is_living`: حالة الحياة (TRUE/FALSE)
- `birth_year_type`: نوع تاريخ الميلاد (hijri/gregorian)
- `birth_year`: سنة الميلاد
- `death_year_type`: نوع تاريخ الوفاة (hijri/gregorian)
- `death_year`: سنة الوفاة
- `birth_date`: تاريخ الميلاد (YYYY-01-01)
- `death_date`: تاريخ الوفاة (YYYY-01-01)
